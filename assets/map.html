⚠ 电池没设「不限制」：系统会把玄武冻停，位置跳回真实。点这里看你手机品牌怎么设 ›
位置跳回真实，多半是电池白名单没做。按你的手机品牌对号入座：
华为 / 鸿蒙：设置 → 应用和服务 → 应用启动管理 → 玄武定位 → 关掉「自动管理」，自启动 / 关联启动 / 后台活动三个开关全开；再进应用信息 → 耗电 → 选「不限制」。
小米：设置 → 应用设置 → 应用管理 → 玄武定位 → 打开「自启动」，省电策略选「无限制」。
OPPO / 一加：设置 → 电池 → 应用耗电管理 → 玄武定位 → 打开「允许完全后台行为」与「允许自启动」。
vivo：设置 → 电池 → 后台耗电管理 → 玄武定位 → 选「允许高后台耗电」，并在应用管理里开自启动。
三星：设置 → 电池 → 后台使用限制 → 「从不自动休眠的应用」里加上玄武定位。
其他安卓：设置 → 应用 → 玄武定位 → 电池 → 选「不限制」。

微信等 App 显示真实位置？点这里看三招 ›
微信用的是腾讯自家定位，会扫 Wi-Fi 算真实位置。三招逼它走系统定位：
1. 先做个测试：关掉 Wi-Fi（只留移动数据）重启微信，看位置对不对 — 对了就是 Wi-Fi 在出卖你；
2. 手机设置 → 定位 → 定位模式改成「仅限设备（GPS）」；
3. 定位设置里关掉 Wi-Fi 扫描、蓝牙扫描，改完重启微信。
三招都用了还不行，是它在过滤带标记的模拟位置，免 root 到头了（高德不挑，微信挑）。

还差一步：把玄武设为模拟位置应用

这是安卓系统的规矩，不是 App 的限制。设置一次，以后一直生效。
1
先开开发者选项
设置 → 关于手机 → 连点「版本号」7 次（已经开过可跳过）。
2
选玄武定位
下方按钮打开开发者选项 → 找到「选择模拟位置信息应用」→ 选「玄武定位」。
