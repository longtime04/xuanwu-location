# 玄武定位（Xuanwu Location）

![玄武定位图标](icon.png)

**安卓模拟定位工具**：地图点选、地点搜索、收藏、分享导入、经纬度输入、摇杆漫游、路线模拟，一应俱全。干净免费、**无广告、无统计、不上传位置**，界面是整套玄武主题（墨玉 + 金线）。

已在鸿蒙 4.2 真机实测可用：高德地图等普通应用能读到模拟位置，长时间挂着也稳（服务带防冻结保活）。

## 快速上手（3 步）

1. **装 APK**：点上面的长期链接下载安装。
2. **把玄武设为模拟位置应用**（安卓系统的统一规矩，设置一次长期生效）：先开开发者选项（设置 → 关于手机 → 连点「版本号」7 次）→ 进开发者选项 →「选择模拟位置信息应用」→ 选「玄武定位」。第一次打开 App 时有向导带着你走。
3. **做电池白名单**（重要！不做这一步，系统省电会把玄武冻停，位置过一会儿就跳回真实）：华为 / 鸿蒙走「设置 → 应用和服务 → 应用启动管理 → 玄武定位 → 关掉自动管理 → 自启动 / 关联启动 / 后台活动三个开关全开」。其他品牌的做法在 App 底部的橙色横条里，点开有分品牌图文教程。

做完这 3 步，选个点，点金色大按钮「开始模拟」就行了。

## 操作方法

- **选点**：直接点地图；或用顶部搜索框（高德数据，中文地名准）；或从收藏夹里选。
- **开始 / 停止模拟**：金色大按钮。模拟中可以放心切到别的 App，位置会一直保持；选了新地点时按钮变「切换到此处」；不用了点「停止模拟」。
- **底部面板**：按住面板顶部的小横条可以**下拉收起**（把地图让出来慢慢选点），上滑或轻点横条展开。
- **摇杆漫游**：模拟中点「摇杆」→ 首次需给一次悬浮窗权限 → 屏幕右侧出现摇杆，推杆往任意方向走，推得越满速度越快（上限约行车速度）；地图上的小玄武龟标记会跟着你移动。
- **路线模拟**：点「路线」→ 在地图上点两下定起点 A 和终点 B → 选速度（步行 5 / 骑行 15 / 驾车 40 km/h）→「开始路线」，位置沿直线匀速移动，顶部状态行显示进度，到达 B 点后自动停住。
- **分享导入**：在高德 / 百度 / 谷歌地图里对某个地点点「分享」→ 选「玄武定位」，坐标会自动解析并跳过去，你点「开始模拟」即可；国内地图的坐标偏移已自动校正。别人发你的位置文本或链接，也可以在「坐标」面板里粘贴解析。
- **手输经纬度**：点「坐标」按钮，填纬度、经度，并选对坐标系：从高德 / 微信 / 腾讯地图复制的选 **GCJ-02**；GPS 设备、谷歌地球的选 **WGS-84**；百度地图的选 **BD-09**。选错会偏几百米。
- **收藏**：选好点后点「☆ 收藏」起个名字保存；下次在收藏夹点「前往」直达；搜索时收藏过的名字会立刻秒出。

## 注意事项（重要）

- **防作弊应用测得出**：模拟位置带有安卓系统的「测试」标记。普通地图、社交、外卖、打车软件一般可正常读到；但**钉钉、企业微信等带防作弊检测的应用会识别模拟定位**——本工具不对此做任何绕过处理，请勿用于考勤打卡等场景。
- **位置跳回真实**：99% 是电池白名单没做（见快速上手第 3 步），不是 App 坏了。App 里运行时有自检计数（已注入 N 次 · ✓ 系统已接受），状态行会告诉你模拟是否真的被系统接受。
- **微信显示真实位置**：微信走腾讯自家定位（会扫周围 Wi-Fi 算真实位置）。三招：① 先关掉 Wi-Fi 只留移动数据、重启微信做个测试（变对了就是 Wi-Fi 在"出卖"你）；② 定位模式改「仅限设备（GPS）」；③ 在定位设置里关掉 Wi-Fi 扫描、蓝牙扫描后重启微信。三招都用了还不行，是它在过滤带测试标记的位置，免 root 无解。App 底部有同款「三招」贴士卡。
- **偏了几百米**：多半是坐标系选错，或经纬度填反（纬度在前、经度在后；中国范围内纬度 3~55、经度 73~137）。
- **权限说明**：本 App 只申请定位、网络、悬浮窗（摇杆用）、前台服务与唤醒锁（保活用），不申请通讯录、短信、存储等无关权限。

## 隐私

位置只在本机用于注入系统测试通道，**不上传、不统计、无任何广告或统计 SDK**。搜索功能会把你输入的关键词发给高德或 OpenStreetMap 的公开搜索接口（和你在任何地图 App 里搜索一样），除此之外没有任何数据离开你的手机。

## 构建

手动流水线（aapt2 → javac → d8 → zipalign → apksigner），需要 JDK 21 与 Android SDK build-tools 34：

```bash
./build.sh
```

- 签名：把你自己的 `keystore.jks` 放到仓库根目录再构建（脚本会自动用它签名；没有 keystore 时产出未签名包并给出提示）。
- 高德高速搜索（可选）：在 `src/com/muse/xuanwu/AmapKey.java` 填入你自己在高德开放平台申请的「Web 服务」Key；不填则搜索自动走 OpenStreetMap 兜底（稍慢，仍可用）。
- 界面是 WebView + 本地打包的 Leaflet，地图瓦片来自高德公开瓦片服务。
